Primal Logic operates within a dual-form framework, admitting two complementary regimes that represent the fundamental states of the system.

**Within the PLR interpretive synthesis, this state is equated to Hell**, representing unbounded chaos and informational decay.

**Mathematical Definition:**
```

```

**Characteristics:**
- Partial truth accessibility

- Non-idempotent operations

### 4.2 The Closed Form (Heaven)

The Closed Form is a state defined by:
- Boundary-saturated, self-constraining closure
- Fixed-point equilibrium
- Information differential resolution

In this regime, the system collapses into equilibrium at a **fixed point (x*)** where all information differentials are resolved.

**Mathematical Definition:**

**Within the PLR framework, this state is equated to Heaven**, representing deterministic stability and logical completion.

**Characteristics:**

- Idempotent operations: ∃x* ∈ S : Φ(x*) = x*
- O(n) computational complexity
